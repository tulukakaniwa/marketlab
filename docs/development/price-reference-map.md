# 量价地图

量价地图复用已有 `buildVolumePriceProfile` 查询及成本带，为 Vela 和 HQ
主图增加历史成交密度节点。它是研究图层，`executionAuthority: none`，不进入默认挂单计划。

## 计算与可用时间

- 固定最近 60 个连续有效、已收盘会话，36 个价格桶；8 会话后出图。
- 按每日高低区间分摊 OHLCV 成交量，属于成交密度代理。
- 最大密度桶 POC 优先，再选强度较高且至少间隔 3 桶的节点，最多 3 个。
- 每个历史点重新使用截至当日的窗口，桶边界与强度均不引用未来数据。
- 强度为本桶量除以当时窗口最大桶量；占比为本桶量除以当时窗口总量。
- 坏行、未收盘、乱序、缺失和数值溢出断段，重新预热。零量不分配量；全窗口零量显示无量。
- 缺少 closure 标记时沿用本项目日线 CSV 已收盘数据契约；不能用于未闭合的实时行情。

纯领域 iterator 允许 ViewModel 每 32 点让出事件循环。切换标的、观察日期或关闭
地图会同步清空旧结果、取消旧批次，过期结果不能回写。保留整个已选历史，不静默截断路径。

## 显示契约

在主图“显示”中切换“量价地图”，默认开启。圆点面积表达当日窗口内相对密度，
不是跨日期绝对成交量比较。琥珀表示价位在该日收盘之上（含所在桶），青蓝表示下方，
POC 加描边。图例按十字光标日期显示节点价格、窗口样本数，展开可看占比和口径。

淡色区沿用已有成本带，只在地图、价格带、成本带均开启时绘制。填色按历史日期匹配，
不回填到预热或缺口，也不向观察日之后延伸。当前场景输入不改变成交密度节点。

两个引擎使用同一 painter、节点快照与颜色。缩小后仅做像素级抽样，保留最新可见点；
抽样不改变领域值。HQ 使用原生价格变换（含对数轴）、DPR 和真实周期结束日期，
周月 K 只显示该周期结束会话的节点，保留期间坏数据造成的填色断口。

这些节点不是交易所逐笔成交、订单簿、真实筹码持仓、期权资金流或市场 Gamma 暴露。
图层不产生新的买卖箭头、执行指令或收益证明。

## 验证范围

回归测试覆盖前缀一致性、数值边界、坏数据断段、异步取消、精确日期图例、开关、
两引擎接线、共享绘制、HQ 周期日期/原生坐标/DPR，以及切换资产后的旧图层清空。
自动测试不能替代最终视觉检查；本轮浏览器工具的本地页面访问被安全策略拒绝，
因此未声明实机目测通过。
